AquaLook — mettre à jour un module

‹ Mes modules

Quand « Mes modules » annonce une nouvelle version, l’installation se fait depuis le module lui-même, avec un ordinateur, une tablette ou un téléphone connecté au même Wi-Fi que lui. L’espace en ligne ne lance jamais de mise à jour à votre place : c’est vous qui décidez du moment.

Pages Web (l’interface du module)

  1. Trouvez l’adresse du module : sur son écran, ADMIN › WiFi, ligne « Etat WiFi » (par exemple 192.168.1.141).
  2. Ouvrez cette adresse dans le navigateur, puis connectez-vous avec le mot de passe Web du module.
  3. Ouvrez la page des mises à jour : badge ⬆ MAJ en haut de l’accueil s’il est affiché, sinon directement http://adresse-du-module/ota.html.
  4. Cliquez sur « Mettre à jour les pages Web » et confirmez.
  5. Le module redémarre en mode maintenance (écran violet) pendant environ deux minutes, télécharge les fichiers, vérifie chacun, puis revient tout seul.
  6. Rechargez la page : elle doit indiquer « Tout est à jour ». Dans « Mes modules », la nouvelle version apparaît après la synchronisation suivante du module.

Pas pendant un arrosage : le module refuse tant qu’une zone arrose. L’arrosage programmé n’est pas affecté par la mise à jour. Si quelque chose échoue, les pages actuelles sont conservées et la page explique pourquoi.

Programme du module (firmware)

Sur la même page des mises à jour, la colonne « Programme du module » se fait en trois étapes, dans l’ordre : Vérifier, Préparer, Installer. Chacune s’active quand la précédente a réussi. Si le nouveau programme ne démarre pas correctement, l’ancien est restauré automatiquement.

Si la page indique qu’aucun programme n’est disponible pour ce module, sa mise à jour se fait pour l’instant par câble, par la personne qui assure sa maintenance.

Pourquoi c’est sûr

Chaque mise à jour est signée par l’éditeur d’AquaLook. Le module vérifie cette signature avant d’installer quoi que ce soit, et refuse un paquet modifié ou d’origine inconnue, même s’il vient d’un serveur. Il vérifie ensuite chaque fichier un par un.
