Scripts

Un script décide d'ouvrir, de suspendre ou de reprendre l'arrosage d'une zone, à partir de ce que voient les entrées. Il est écrit ici, compilé par le navigateur, puis vérifié et signé avant que le module ne l'accepte.

À quoi servent les trois champs
EmplacementLe module garde six scripts, numérotés de 1 à 6. Choisir un emplacement, c'est choisir lequel des six on écrit. Enregistrer remplace ce qui s'y trouvait ; les cinq autres ne bougent pas.
NomSert uniquement à vous y retrouver dans la liste. Le module ne s'en sert pour rien d'autre que le journal.
Déclenché par
l'entrée		L'identifiant de l'entrée qui réveille ce script — celui déclaré dans « Câblage relais », pas un numéro de broche. Le script part quand la valeur stabilisée de cette entrée change, dans un sens ou dans l'autre. Un contact qui claquette ne déclenche rien : l'anti-rebond l'absorbe. Laisser 0 pour un script qu'on ne lance qu'à la main.
ActifUn script inactif reste enregistré mais ne part jamais tout seul. Pratique pour le mettre au point sans qu'il agisse.

Ce que fait chaque bouton. « Vérifier » compile sans rien envoyer et signale la ligne fautive s'il y en a une. « Enregistrer » compile, signe et dépose sur le module — qui revérifie et peut refuser, auquel cas le script précédent reste intact. « Lancer maintenant » exécute le script tout de suite, sans attendre l'entrée : c'est ainsi qu'on l'essaie. « Secret » pose ou change le mot de passe d'écriture du module.

Deux scripts au plus tournent en même temps, et un script déjà en cours n'est pas relancé si son entrée rebascule. Un déclenchement qui n'a pas pu partir est écrit dans le journal du module — il n'est jamais avalé en silence.

Choisissez un emplacement.

Le script

Mémo du langage
si <condition> alors ... sinon ... finsi
tantque <condition> faire ... fintantque
pour a de 1 à 5 faire ... finpour

attendre <secondes>          rend la main, n'occupe pas le module
demarrer zone <id> pendant <secondes>
arreter zone <id>            arrêt franc, le reliquat est perdu
suspendre zone <id>          conserve le reliquat
reprendre zone <id>          repart pour le reliquat conservé
message <code>

a = <expression>             variables a à h

entree(<id>)      valeur stabilisée d'une entrée : 0 ou 1
zoneactive(<id>)  la zone arrose-t-elle : 0 ou 1
reste(<id>)       secondes restantes sur la zone

+ - * / %   == != < <= > >=   et  ou  non   ( )
# commentaire jusqu'à la fin de la ligne

Les identifiants de zone et d'entrée sont STABLES : ils ne changent pas
quand une zone est renommée ou déplacée dans la liste.
