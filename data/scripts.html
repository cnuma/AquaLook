Scripts

Un script décide d'ouvrir, de suspendre ou de reprendre l'arrosage d'une zone, à partir de ce que voient les entrées. Cliquez une commande à gauche ou une référence à droite : elle s'insère à l'endroit du curseur.

Commandes

Script INACTIF : il ne démarre jamais seul, et « Lancer maintenant » le refuse aussi (« script desactive ») — repassez « Actif » à « oui » pour l'utiliser.
Choisissez un emplacement.
À quoi servent les champs ci-dessus
EmplacementLe module garde six scripts. Enregistrer remplace celui-ci ; les cinq autres ne bougent pas.
NomPour vous y retrouver dans la liste et dans le journal.
Déclenché parCe qui réveille le script. Tous les modes surveillent une transition, jamais un état : le script part une fois, au moment où ça change.
Le changement d'une entrée — sa valeur stabilisée bascule, dans un sens ou dans l'autre ; un contact qui claquette ne déclenche rien.
Le démarrage / l'arrêt d'une zone — au moment où elle s'ouvre ou se ferme, quelle qu'en soit la cause : planning, marche forcée, ou un autre script.
Rien — le script ne part que par « Lancer maintenant ».
Un même script ne repart pas deux fois en moins de cinq secondes : c'est ce qui empêche un script commandant sa propre zone de boucler.
ActifUn script inactif reste enregistré mais ne part jamais seul.

Vérifier compile sans rien envoyer et signale la ligne fautive. Enregistrer compile, signe et dépose — le module revérifie et peut refuser, auquel cas le script précédent reste intact. Lancer maintenant l'exécute sans attendre l'entrée. Quatre scripts au plus tournent en même temps (deux sur l'ancienne carte CYD) ; un déclenchement ou un « lancer script » qui n'a pas pu partir est écrit dans le journal du module.

Bibliothèque de phrases — ce que « notifier » enverra sur le téléphone

Un script écrit notifier 900 ; sur le téléphone, l'utilisateur lit la phrase associée au code 900. Le code n'est qu'un renvoi : corrigez la phrase ici une fois, tous les scripts qui la citent en profitent. Rangée sur la carte SD du module ; en cas de panne SD, le script envoie le code nu.
