Scripts

Un script décide d'ouvrir, de suspendre ou de reprendre l'arrosage d'une zone, à partir de ce que voient les entrées. Cliquez une commande à gauche ou une référence à droite : elle s'insère à l'endroit du curseur.

Commandes

Choisissez un emplacement.
À quoi servent les champs ci-dessus
EmplacementLe module garde six scripts. Enregistrer remplace celui-ci ; les cinq autres ne bougent pas.
NomPour vous y retrouver dans la liste et dans le journal.
Déclenché par
l'entrée		L'identifiant d'une entrée du panneau de droite. Le script part quand sa valeur stabilisée change, dans un sens ou dans l'autre — un contact qui claquette ne déclenche rien. Laisser 0 pour un script lancé uniquement à la main.
ActifUn script inactif reste enregistré mais ne part jamais seul.

Vérifier compile sans rien envoyer et signale la ligne fautive. Enregistrer compile, signe et dépose — le module revérifie et peut refuser, auquel cas le script précédent reste intact. Lancer maintenant l'exécute sans attendre l'entrée. Deux scripts au plus tournent en même temps ; un déclenchement qui n'a pas pu partir est écrit dans le journal du module.
