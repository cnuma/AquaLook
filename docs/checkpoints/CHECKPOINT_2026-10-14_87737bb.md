## 8. Risques et limites

- `.141` exécute le firmware 5.17.2 alors que `VERSION` vaut 5.17.3 (montée
  pour le paquet Web seul, comme 5.16.1) : normal, pas de release 5.17.3 du
  programme. Une release du programme exige `VERSION` = étiquette, supérieure
  à 5.17.2 : 5.17.3 (en taguant `main`) ou une version suivante.
- Un module en 5.17.1 ne peut plus suivre l'OTA : flash USB obligatoire.
- Cache GitHub et AlwaysData : attendre ~1 min après une publication avant de
  vérifier.
- `ubuntu-latest` passe sur Ubuntu 26 le 19 oct. : retiré de la TODO par le
  propriétaire ; un échec du workflow `ota-release.yml` à la prochaine release
  viendrait probablement de là.
