## 9. Procédure exacte de reprise

```powershell
git fetch origin
git checkout main
git pull --ff-only
git log --oneline -3
git status --short
git -c core.whitespace=cr-at-eol diff --check
python tools/editeur_banc.py
```

Rien à reflasher. Pour une page Web : `python tools/module_session.py deploy
data/<page>` (mot de passe Web lu dans `.env`). Pour un développement
firmware, demander le port COM, puis :

```powershell
python tools/soak/announce_reboot.py
pio run -e ProgrammeArrosage_s3 -t upload --upload-port <PORT_COM>
pio device monitor -p <PORT_COM> -b 115200 --dtr 1 --rts 0
```
