## 8. Risques et limites

- **P2.19** : un module ne quitte pas de lui-même une borne faible quand une meilleure revient ; seul un redémarrage le fait changer.
- **P3.29** : `http://jardin-03.local` peut être lent ou injoignable alors que l'IP répond ; le module ne s'annonce en mDNS qu'au premier Wi-Fi.
- Les modules déjà réglés en `http://ntfy.sh` le restent : réenregistrer `https://ntfy.sh` sur chacun.
- Aucun outil versionné pour l'envoi FTPS d'un paquet Web : la procédure est manuelle ou par script de session ; à intégrer (P2.18 ou `tools/`).
- Manifeste Web : ~7 000 o sur 8 192.
- Compiler depuis un worktree au chemin long échoue (limite Windows de 260 caractères) : `subst` ou chemin court.
- Git Bash convertit les arguments commençant par `/` : `MSYS_NO_PATHCONV=1` ou PowerShell.
