## 7. Risques et limites

- **`/editeur/` et paquet Web en retard** : l'éditeur en ligne et les autres
  modules n'ont pas les trois évolutions de la nuit (voir §8).
- Les comptes d'utilisation reposent sur le **texte source** des scripts. Un
  script dont le texte est absent de la SD est signalé « non vérifié » dans
  l'info-bulle mais **n'est pas compté** dans la puce.
- Analyse textuelle simple (`message|notifier <code>`, `g<n>`, commentaires
  retirés) : suffisante pour le langage actuel ; à revoir si la syntaxe évolue.
- En local, chaque ouverture d'onglet Phrases/Variables et chaque
  confirmation relit jusqu'à 5 textes de scripts (`/api/script-source`).
- Fixer une nouvelle valeur d'une variable citée ne demande pas de
  confirmation (choix assumé, signalé à l'utilisateur).
- Le banc headless de la session (mock de `fetch`) n'est pas versionné ;
  `tools/script_schema_test.html` ne couvre que la logique du schéma.
- Restent valables les risques de `1534dde` §7 (défaut `'abcdefgh'.indexOf`
  de `script-lang.js`, variables non remontées par CloudSync, etc.).

## 9. Procédure exacte de reprise

```powershell
git fetch origin
git checkout main
git pull --ff-only
git log --oneline -3
git status --short
git checkout -b <feature/...>
```

Demander le port COM courant, puis, pour un changement firmware :

```powershell
git -c core.whitespace=cr-at-eol diff --check
python tools/soak/announce_reboot.py
pio run -e ProgrammeArrosage_s3 -t upload --upload-port <PORT_COM>
pio device monitor -p <PORT_COM> -b 115200 --dtr 1 --rts 0
```

Pour une page Web seule, dépôt direct sur la SD de `.141` (autorisé d'office
par l'utilisateur depuis le 8 oct. 2026, pages Web uniquement) :
`POST /api/debug/deploy-begin`, `POST /api/debug/deploy-file?name=<fichier>`
(corps binaire), `POST /api/debug/deploy-commit`, puis comparer le SHA-256 de
`GET /<fichier>` au fichier local ; l'utilisateur recharge avec Ctrl+F5.

Contrôles rapides sans secret : `GET /api/diagnostics` (champ `build`),
`GET /api/debug/script-selftest`, `GET /api/script-globals`.

Piège outil : un heredoc bash mange les barres obliques inverses d'un script
Python ; écrire les scripts de transformation dans un fichier.
