## 8. Risques et limites

- `.141` signale `environment-mismatch` à chaque vérification de version : attendu tant qu'il tourne le binaire de banc.
- Les mesures de largeur se font dans Edge ; police et emoji de l'iPhone plus larges : validation finale à l'œil par le propriétaire.
- `largeur_site.py` sert le site sans PHP : les vues connectées de la console reposent sur ses réponses fictives (`CONSOLE`), à faire suivre si le contrat de `/admin/*` change ; idem `apercu_web/fixtures.js` pour `app.html`.
- Manifeste Web : 7 007 o sur 8 192.
- Git Bash convertit les arguments commençant par `/` (`module_session.py post /api/...`) : lancer depuis PowerShell ou `MSYS_NO_PATHCONV=1`.
- Le classificateur de permissions bloque la création de tag / release sans autorisation explicite du propriétaire.
