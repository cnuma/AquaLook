## 7. Risques et limites

- **Preuve > 4 Ko non faite sur carte** : la plus grosse commande reçue fait
  890 o. `tools/cloud_test_scripts_apply.py` le prouve (bourrage de 10 Ko),
  mais demande le jeton admin de production. Le `.env` local contient un
  jeton qui **n'est pas** celui de production (401).
- **Non testés sur carte** : refus d'un script en cours d'exécution,
  effacement distant, phrases distantes. Ces chemins sont couverts par le
  banc mock de l'interface et par le banc ci-dessus.
- **Pas de signature de bout en bout** (D014) : un serveur compromis peut
  installer un script, qui partira au prochain déclencheur local. Ce risque
  est borné par la durée maximale de sécurité.
- **Une commande en vol par module** : un utilisateur qui modifie un script
  puis le planning reçoit un 409 « réessayez dans quelques minutes ».
- **Miroir** : 48 ms dans la boucle principale, une fois par changement de
  révision (lecture SD). Le chemin MaintenanceBoot ne remonte que les
  en-têtes des scripts.
- **Observation non corrigée** : après l'application d'une commande, le
  journal affiche « premiere echeance dans 5 min ». `_ackSyncSoon` remet
  `_lastSyncEpochSec` à 0, ce qui fait passer par la branche « première
  exécution ». L'accusé part quand même en ~45 s grâce à la règle du
  changement de révision. Comportement antérieur à ce chantier.
- **TODO ROADMAP** : dans la grille de `app.html`, un créneau supprimé en
  attente reste invisible. Le même cas pour un script est, lui, traité dans
  l'éditeur.
- `dist/alwaysdata` (5.9.49) est périmé.

## 10. Procédure exacte de reprise

1. Lire `AGENTS.md`, `docs/REPRISE_INGENIEUR.md`, puis ce document.
2. Se placer sur la branche :

```powershell
git fetch origin
git checkout feature/cloud-scripts
git pull --ff-only
git log --oneline -3
git status --short
```

3. Demander le port COM courant (COM4 sur le poste habituel).
4. Chaîne S3 :

```powershell
git diff --check
pio run -e ProgrammeArrosage_s3 -t upload --upload-port <PORT_COM>
pio device monitor -p <PORT_COM> -b 115200 --dtr 1 --rts 0
```

5. Bancs :

```powershell
& "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless --disable-gpu --allow-file-access-from-files --dump-dom "file:///<chemin-du-depot>/tools/script_schema_test.html"
$env:AQUALOOK_ADMIN_TOKEN = '<jeton admin de production>'
python tools/cloud_test_scripts_apply.py --module-ip 192.168.1.141 --slot 3
```

Rappels du banc :
- avant un flash pendant le soak, lancer `python tools/soak/announce_reboot.py`, puis committer le registre ;
- les fichiers `.cpp` modifiés par script doivent garder CRLF ;
- `WebManager.cpp` et `CloudSync.cpp` ne contiennent plus d'octet NUL : `git diff` y redevient textuel.
