## 7. Risques et limites

- Non essayés en production (banc seulement) : **invitation** depuis la
  console, **changement de mot de passe** connecté (carte « Mon compte »),
  durée de `forgot` sur une adresse **connue** (≈ 26 ms au banc, à confirmer
  sur AlwaysData : sans `fastcgi_finish_request`, le repli
  `Content-Length` + `Connection: close` doit garder la réponse rapide).
- Un compte invité dont le lien expire reste inutilisable jusqu'à une
  nouvelle invitation ou un « mot de passe oublié » (voulu).
- `forgot` sur une adresse inconnue compte dans `mail_log` (`inconnu`) et
  donc dans le plafond journalier : des demandes massives depuis plusieurs IP
  peuvent épuiser `MAIL_MAX_PER_DAY` (même logique que les refus de plafond
  existants).
- Restent valables : §7 de `CHECKPOINT_2026-10-10_7bc3990.md` (Oublier le
  compte sans détachement, `hw_id` libre bloquable, `FORCE_SYNC_MIN_GAP_SEC`

  commande qui attend un intervalle complet) et du checkpoint `370a6eb`

## 9. Procédure exacte de reprise

```powershell
git fetch origin
git checkout main
git pull --ff-only
git log --oneline -3
git status --short
git checkout -b <feature/...>
```

Demander le port COM courant, puis, pour un changement firmware :

```powershell
git -c core.whitespace=cr-at-eol diff --check
python tools/soak/announce_reboot.py
pio run -e ProgrammeArrosage_s3 -t upload --upload-port <PORT_COM>
pio device monitor -p <PORT_COM> -b 115200 --dtr 1 --rts 0
```

Flash de `.141` autorisé d'office par le propriétaire ; dépôt d'une page
`data/` sur la SD de `.141` aussi. Publication AlwaysData : par le
propriétaire (FTP), jamais par l'agent ; lui donner la liste exacte des
fichiers avec leur chemin `cloud/php-mutualized/…` et leur taille, et
rappeler qu'un paramètre nouveau n'apparaît dans Console > Paramètres
qu'une fois `settings.php` publié.

Banc serveur local : MariaDB portable
`C:\Users\Emman\mariadb-local\mariadb-12.3.2-winx64` (`--port=3307`), base
`aqualook_banc_d` (schémas v1 à v7). Serveur PHP de banc avec SMTP factice :
variables d'environnement `DB_NAME`, `ADMIN_TOKEN`, `MAIL_SMTP_*`,
`MAIL_SMTP_CAFILE` (certificat auto-signé `CN=localhost`), `APP_BASE_URL`,
puis `php -d extension=openssl -S 127.0.0.1:8003 router.php` (les variables
d'environnement priment sur le `.env`, qui n'est pas touché). Scripts du banc
(SMTP TLS factice, scénario 44 points, équivalent `requests` en urllib — le
module `requests` n'est pas installé) : non versionnés, à recréer depuis §3.
Pas de Node sur le poste : JS contrôlé par `tools/check_inline_js.py` et
rendu Edge headless (`msedge --headless=new --dump-dom`).

Pièges : `git diff --check` simple signale à tort les CR (utiliser
`-c core.whitespace=cr-at-eol`) ; un heredoc bash mange les `\n` et `\0`
(passer par l'outil d'édition) ; les sources serveur sont en CRLF ; le
cookie de session est `Secure` (un client HTTP de banc doit le renvoyer à la
main).
